# dependency-graveyard
Paste a package.json, your dependency becomes a graveyard: Who's alive, who's a zombie, who's a ghost, who's buried.

## Kiro workspace configuration

This repository includes active Kiro workspace guidance in [`.kiro/steering`](.kiro/steering)
and a visual-refresh specification in [`.kiro/specs/halloween-graveyard-refresh`](.kiro/specs/halloween-graveyard-refresh).
These files guide ongoing work; they do not represent a historical record of how
existing files were created.
